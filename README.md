## 🚀 Live Preview & Architecture

This portfolio has been engineered from the ground up without heavy, slow third-party frameworks. It runs on pure, standards-compliant HTML5, modular CSS3, and vanilla JavaScript for blazing fast load speeds and 100/100 Lighthouse performance.

### ✨ Key Features Built In:
- **Interactive Backend UPI Simulator**: Test the transaction state-machine live in the browser with real edge cases (Standard 200 OK, Insufficient Balance Exception, Invalid Recipient VPA, and Circuit Breaker Network Timeout).
- **Interactive Code & Architecture Console**: Real Java production-style service layer code with syntax highlighting and JSON system design metadata.
- **Quick Command Palette (`Ctrl + K` / `Cmd + K`)**: Instantly jump to any system, project, credential, or action using the keyboard.
- **Fluid Ambient Cursor Glow**: Hardware-accelerated cursor spotlight layer.
- **Dynamic Category Filtering**: Seamlessly filter between Java & Backend, Full-Stack, and Modern React Frontend systems.
- **Instant Contact & Clipboard Integration**: Quick-copy email with toast notifications and pre-formatted mail client bridging.

## 🛠️ How to Run Locally

You can open `index.html` directly in any web browser, or use a lightweight local server:

```bash
# Using VS Code Live Server:
Right-click index.html -> "Open with Live Server"

# Or using Node / npx:
npx serve .

# Or using Python 3:
python -m http.server 3000
```

## 🌐 One-Click Deployment Options

### GitHub Pages:
1. Push this folder to your repository: `https://github.com/nikre01/portfolio`
2. Go to **Settings** -> **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your portfolio will be live at `https://nikre01.github.io/portfolio`.

### Vercel:
Run `npx vercel` inside this folder or import your GitHub repo directly into Vercel Dashboard.
